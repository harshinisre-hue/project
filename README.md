# IMDB Review NLP 

Trained a machine learning model (Support Vector Machine Training) to classify sentiment of a movie review achieving a ~90% accuracy rate. 

## Core files
── IMDB_DATASET.csv       # Containing reviews and sentiment labels (positve or negative)

── preprocessor.py        # Removes stopwords, punctuation + tokenization of words

── model.py               # Trains a Support Vector Machine

── confusionmatrix_imdb.png     # Generated Confusion Matrix to show accuracy on Test (20% of the Dataset)
